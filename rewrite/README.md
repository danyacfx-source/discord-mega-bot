# Legacy: альтернативная сборка бота

`rewrite/` — исторический эксперимент с отдельным `Bot`, набором адаптеров и
composition root. Он **не является** production-точкой входа: рабочий запуск
выполняется через `main.py`, а актуальный граф зависимостей находится в
`app/core/composition.py`.

Пакет остаётся в репозитории временно, потому что его полезно использовать как
reference при проверке границ зависимостей. Новые команды, интеграции, миграции
и исправления поведения добавляются только в `app/`.

## Правила поддержки

- Не импортировать `rewrite.*` из production-кода.
- Не запускать `python -m rewrite.main` на боевом сервере.
- Не дублировать тесты для двух путей запуска.
- При следующем архитектурном ревью удалить пакет целиком, если больше не нужен
  для сравнения DI-подходов. Перед удалением убедиться, что `tests/test_rewrite.py`
  больше не нужен либо перенесён в тесты `app.core.composition`.
