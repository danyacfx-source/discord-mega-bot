# DENDICH / RADIO SILENCE

Единая визуальная система веб-админки Discord-бота и публичной страницы `/showcase`.

## Что обновлено
- Панель `/admin`: новая навигация, типографика, компоненты, карточки, формы, тёмная и светлая темы.
- Публичная витрина `/showcase`: новый главный экран, Twitch/Kick, статус текущего эфира, статистика Discord, события, медиатека и меценаты.
- Встроенный предпросмотр витрины в панели использует **тот же** компонент `showcase-page.jsx`.
- Авторизация паролем и Discord OAuth, API и все функции Discord-бота сохранены.
- Удалены исходные аниме-тема и фон. Новый фон — лёгкий SVG `radio-terrain.svg`, иконка — `icon.svg`.
- Для мобильных экранов используются адаптивные сетки и меню.

## Проверка локально
```bash
cd panel-ui
npm ci
npm run build
npm run dev
```
Откройте `http://localhost:5173/admin` и `http://localhost:5173/showcase`.
Для реальных данных и авторизации должен быть запущен Python-бэкенд, на который проксируются `/api` и `/oauth`.

В GitHub Actions помимо Python-проверок выполняется сборка Vite и браузерные smoke-тесты для десктопа и телефона. Скриншоты тестов доступны среди артефактов запуска CI и содержат **тестовые**, а не реальные данные сервера.

## Публикация
Docker теперь пересобирает интерфейс из `panel-ui/` в отдельном Node-стейдже и копирует свежую папку `dist` в финальный Python-образ. Старую зафиксированную в Git сборку Docker не использует.

После получения изменений на сервере:
```bash
git pull
docker compose up -d --build
docker compose ps
```
Без пересборки Docker сервер может продолжать показывать старые статические файлы. Для развёртывания **без Docker** выполните `cd panel-ui && npm ci && npm run build` перед перезапуском бота.

Никакие файлы `.env`, токены, пароли, пользовательские данные или рабочая БД в ребрендинге не изменяются.
